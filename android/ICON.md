# Android launcher icon

Artwork: [drawable-nodpi/porymap_icon_art.png](res/drawable-nodpi/porymap_icon_art.png)

Generated with the built-in `image_gen` tool. The transparent PNG is kept unchanged; Android's foreground drawable supplies a 15% inset, and the adaptive icon supplies the slate background. A separate native vector provides the monochrome themed-icon layer.

Prompt used:

> Use case: logo-brand. Asset type: Android adaptive launcher icon foreground for Porymap Android, a pixel-art game map editor. Create an original, beautifully readable chunky pixel-art emblem: a small folded tile map showing simple green land, a winding sandy path and blue water, with one bold golden editing pencil crossing a corner. Polished 16-bit game-editor aesthetic, crisp deliberately pixel-stepped edges, restrained detail, strong silhouette recognizable at 48 pixels. Harmonize with a muted dark-slate and mint app UI; the map itself uses fresh mint/grass greens, warm sand and clear blue, pencil is warm gold. Single centered emblem, no words or letters, no characters, no logos copied from existing apps, no mockup, no shadows outside the emblem. Entire emblem fits inside the central 60 percent of a square canvas, leaving a generous transparent margin on every side for Android icon masks. Genuine transparent background, no enclosing rounded-square background: Android supplies the slate background separately. Deliver one square high-resolution PNG.

Android adaptive-icon guidance: https://developer.android.com/develop/ui/compose/system/icon_design_adaptive
